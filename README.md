<h3 align="center">Alyacup — Image Overlay for Windows</h3>


## 🪷 Instruction

- Right-click the image to open the options menu.

- Select an image to display (supports GIF, PNG, JPG).

- In Resize Mode, you can change the size of your image.

- In Transparency Mode, use the mouse wheel (up/down) to adjust opacity.

- In Fixed Mode (Click-through), the image ignores mouse clicks. To close the app, use the "Exit" button in the Windows Taskbar.

- You can use samples from the `/images` directory.
